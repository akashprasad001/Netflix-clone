# 🎬 Netflix Clone

A responsive **Netflix-inspired landing page** built using **HTML and CSS**. This project recreates the visual design and layout of Netflix's homepage with a focus on responsive web design and clean UI implementation.

> **Note:** This is a personal educational project created for learning and practicing frontend web development. It is not affiliated with or endorsed by Netflix.

## 🚀 Features

* 🎨 Netflix-inspired user interface
* 📱 Responsive design for different screen sizes
* 🖥️ Desktop and mobile-friendly layout
* 🎬 Hero/banner section
* 📺 Content and entertainment sections
* ❓ FAQ section
* 🔗 Social/media-style icons
* ⚡ Clean and structured HTML & CSS

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Bootstrap Icons**
* **Google Fonts**

## 🎯 Purpose

The main goal of this project was to practice:

* Responsive web design
* CSS positioning and layouts
* Flexbox and Grid
* Media queries
* Background images and overlays
* Typography and spacing
* Building a real-world website UI from scratch
